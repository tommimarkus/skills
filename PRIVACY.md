# Privacy Policy

This repository publishes local Claude Code™, Codex, and GitHub™ Copilot CLI
plugin bundles. The bundled skills do not run a hosted service for Sour Old Geezer and do not
collect, store, or transmit personal data on behalf of Sour Old Geezer.

When an agent uses these skills with third-party services such as GitHub™,
GitLab™, Claude Code™, Codex, GitHub™ Copilot CLI, or local developer tooling, those services and
the user's own credentials and configuration govern any data access, processing,
and retention.
