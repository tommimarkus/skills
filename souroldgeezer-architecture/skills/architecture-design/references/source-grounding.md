- The layout-request `layout_preferences` object (`mode` / `direction` / `density` / `wrapping` / `routing`, plus the ELK Layered tuning knobs, per-node `layer_constraint` / `partition` placement hints, and per-edge `priority` routing hints in `architecture.md` §9) tunes ELK placement/routing as presentation only, and the render-policy `interactive` field (`none` / `svg` / `html` / `both`) controls navigable output; these are utilization levers, not new findings.

- The selected release bundle's `docs/agent-usage.md` guide is the runtime-local fast contract for source JSON authoring, command handoff, and repair loops.
- Cross-notation support is optional upward UML context to ArchiMate through `properties.uml.architecture_context` and `relationship: "elaborates"`; validate referenced ids at the skill level because schema validation alone permits open properties.

- Dediren runtimes before the accessible-name fix emitted SVG with no accessible-name markup (`role`, `aria-*`, `<title>`, `<desc>`), failing WCAG 2.2 SC 1.1.1 (<https://www.w3.org/TR/WCAG22/#non-text-content>); the gap went upstream, not into local bundle patches, and the release-resolved runtime now emits `role="img"` plus a `<title>` (render-policy `accessibility` block, view-id fallback) and optional `<desc>`. A visible per-view title stays unrendered and a shared policy cannot carry per-view text, so the §9 post-render step (`references/scripts/svg-accessible-name.sh`) completes the accessible name to the view label plus architecture question and adds the visible title into generated output only.

- Dediren 2026.07.14 retired the process-plugin protocol (bundle descriptor v1 → v2: no `plugins[]`, no `elk_helper`, no plugin manifests or executables) and added a one-shot `build` command; the per-stage subcommands and their envelopes were kept, so the decomposed chain still works and only the skill's bundle-introspection assumptions broke. Adopting `build` is what `references/scripts/dediren-build.py` does: verified on the pinned 2026.07.17 bundle against both shipped fixtures — the v1 single-model ArchiMate package with OEF export and the v2 multi-model package whose views render under different notations and policies — with per-view profiles preserved (`archimate` / `uml`) and every declared artifact non-empty. Two shape traps drove the script rather than prose: `build` prints its result document unwrapped, while its `--emit`ted stage files are envelopes the package stores as `.data`, and the export identity fields apply per invocation rather than per view (so exports run one view at a time).

The dediren runtime stays per-package and enforces none of it, so the convention ships as documentation plus review procedure; `properties.identity` verified schema-legal and semantically accepted (`validate` + `validate --plugin generic-graph --profile archimate`, both `ok`) on the pinned 2026.07.17 bundle.
